BUILD: open this folder in Android Studio -> wait for Gradle sync -> Build > Build APK(s).
APK: app/build/outputs/apk/debug/app-debug.apk -> copy to phone and install.
Then press Home -> choose "iPod" -> Always.
CONTROLS: rotate ring = scroll | center = select | hold center = add to playlist / download / remove
ring top = back | left = prev | right = next | bottom = play/pause

CLOUD BUILD (no Android Studio): upload this folder to a GitHub repo -> Actions tab -> "Build APK" -> download artifact "iPod-APK".
